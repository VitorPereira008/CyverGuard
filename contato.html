Sobre o Projeto Educacional

Transparência sobre os objetivos e tecnologias do TCC CyberGuard.

Objetivo Principal

Democratizar o acesso a ferramentas de segurança digital. O CyberGuard não busca substituir soluções empresariais como 1Password ou Bitwarden, mas sim servir como uma porta de entrada educativa para que o usuário comum compreenda a importância da criptografia local e aprenda a identificar fraudes diárias.

Limitações (By Design)

Para garantir a privacidade absoluta (Zero-Knowledge), o cofre não possui banco de dados em nuvem. Isso significa que as senhas não sincronizam automaticamente entre o celular e o computador do usuário; o backup deve ser feito manualmente pelo arquivo JSON.

Stack Tecnológica (Client-Side)

  • HTML5 Estrutura semântica e acessível (A11y).
  • CSS3 Layout responsivo Mobile-First sem frameworks externos.
  • JavaScript ES6 Lógica modular e manipulação dinâmica de DOM.
  • Web Crypto API Criptografia AES-GCM nativa do navegador.
  • Web Storage Persistência local segura sem cookies rastreáveis.

Dúvidas sobre o CyberGuard

Respostas para as principais perguntas sobre a natureza acadêmica e técnica do sistema.

O código-fonte completo está disponível publicamente em nosso repositório no GitHub. Você pode clonar, estudar e utilizar os componentes de interface e os utilitários client-side (como a implementação da Web Crypto API) para fins de estudo acadêmico.
